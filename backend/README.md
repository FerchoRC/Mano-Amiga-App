# Backend Mano Amiga

API del proyecto con Express y PostgreSQL.

## Scripts

```bash
npm run dev
npm start
```

## Variables de entorno

Copia `.env.example` a `.env` y ajusta el valor `DATABASE_URL`.

## Base de datos

```bash
docker compose up -d
```

La base queda disponible en:

- Host: localhost
- Puerto: 5432
- Usuario: manoamiga
- Contraseña: manoamiga
- Base de datos: manoamiga
